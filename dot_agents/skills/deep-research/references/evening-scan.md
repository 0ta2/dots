# 平日夕方イベントスキャン (無人ルーチン)

「会社の価値が一気に動くイベント発生 → 高速に波及分析」の自動化。
Claude Desktop の Scheduled Task (登録は人間) から平日夕方に起動される想定。
このファイルはそのタスクプロンプトから参照される手順書。

## 手順

1. **スキャン** (WebSearch 最大4回): 当日の東証関連の大型イベントを探す。
   今日の日付は最初に `date "+%Y-%m-%d"` で取得する (記憶で補完しない。
   検索結果の「本日」がこの日付と一致するかも必ず突き合わせる)。
   検索例: 「TDnet 適時開示 本日 TOB」「東証 経営統合 発表 今日」「日本株 大型ニュース {今日の日付}」
2. **該当判定**: 下の基準で該当イベントを選ぶ。**1日最大1件** (最も波及が広いもの)。
   迷ったら「該当なし」に倒す (キャップ思想。無理に毎日分析しない)
3. **該当あり** → `/deep-research --event --unattended {イベント概要}` を実行
   (SKILL.md 手順 7 の --unattended ルール: ユーザー入力を求めず md + HTML 納品、
   kabu-lab events.jsonl へ仮想記録、Discord へ結論 1〜3 行 + HTML パス)
4. **該当なし** → 何も送らずに終了する (判断も操作も要らないため)

## 該当イベントの基準

対象 (価値が一気に動く + 波及がある):

- TOB / MBO / 経営統合・合併の発表 (観測報道含む。ただし一次情報と区別して扱う)
- 大型の資本業務提携・大株主の異動
- 業界再編を示唆する行政・規制イベント (例: 地銀再編を促す政策発表)
- 大幅な業績修正・重大な不祥事 (同業への連想が働く規模のもの)

対象外 (分析しない):

- 通常の決算発表・小幅な業績修正
- 個別材料で波及のないもの (その会社だけで完結するニュース)
- 指数・為替など市況一般の動き (イベントドリブンではない)

## 前提 (event-analysis.md と共通)

- 出力は判断材料の整理。売買指示はしない。実弾投入の判断はユーザー
- 勝率は kabu-lab events.jsonl の仮想記録で実測する。成績が悪ければこのルーチンごと止める
  (kabu-lab の流儀: 体感ではなく記録で判定)
