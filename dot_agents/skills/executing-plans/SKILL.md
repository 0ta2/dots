# Executing Plans

計画を確認し、1 タスクずつ完了させる。

## 開始前

1. 計画と参照する spec を読む。
2. 対象リポジトリの状態と固有ルールを確認する。
3. ファイル、インターフェース、依存順、検証方法に実行不能な点がないか確認する。
4. 不明点や重大な欠落があれば、実装を始めずユーザーへ報告する。

## 実行

各タスクについて順番に:

1. そのタスクの Files、Interfaces、全ステップを読み直す。
2. 記載されたステップを順番に実行する。
3. 指定されたテストと検証を実行する。
4. 変更範囲を確認し、そのタスクのファイルだけを commit する。
5. タスクが完了してから次のタスクへ進む。

spec と plan はハーネスの `~/ghq/github.com/0ta2/harness/docs/superpowers/` 配下に置き、
実装 commit には含めない。作業対象のリポジトリには置かない。

## 停止条件

次の場合は推測で進めず、そこで止めて事実と必要な判断を報告する。

- 依存関係や必要なファイルがない
- 計画の指示が曖昧または矛盾している
- 指定された検証が失敗する
- 計画外の変更なしでは次へ進めない
- そのタスクだけを安全に commit できない

全タスク後に計画の検証項目と関連テストを再実行し、結果を報告する。
